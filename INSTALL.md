# rf-site-legal-20 — переносимый скилл

В архиве: папка скилла `rf-site-legal-20/`, необязательный установщик `install.py`, эта инструкция и контрольные суммы `SHA256SUMS.json`. Личные сведения владельца исходного сайта, его код, медиа и реквизиты в пакет не включены.

## Совместимость

Основная часть — стандартный `SKILL.md` с относительными ссылками на `references/`. Она предназначена для агентов, поддерживающих [Agent Skills](https://agentskills.io/specification). `agents/openai.yaml` содержит дополнительное оформление для Codex; другие агенты могут его игнорировать. Нет обязательной зависимости от Exa, MCP, конкретной ОС или framework. Для полноценной правовой проверки агенту нужен доступ к актуальным первичным источникам и к проекту.

«Для всех агентов» означает переносимость инструкций и возможность установки в их каталог навыков, а не автоматическое обнаружение любым существующим продуктом. У каждого агента свой механизм загрузки. Если поддержка Agent Skills отсутствует, подключите `SKILL.md` как инструкции и предоставьте все файлы `references/` через поддерживаемый агентом интерфейс. Это не гарантирует автоматическую активацию.

## Установка без Python

Распакуйте архив. Скопируйте **всю папку** `rf-site-legal-20` в поддерживаемый каталог навыков нужного агента. На конечном пути должен находиться `rf-site-legal-20/SKILL.md`, без лишней вложенности с тем же именем.

Для Codex в этой среде пользовательские навыки размещаются в `$CODEX_HOME/skills`, либо `~/.codex/skills`, если переменная не задана. Для всех чатов/агентов этого пользователя используйте пользовательский каталог, а не папку одного проекта. Для Claude Code личные навыки — `~/.claude/skills/`, проектные — `.claude/skills/`; источник: [официальная документация](https://code.claude.com/docs/en/skills). Для других клиентов проверьте их актуальную документацию и выберите реально поддерживаемый каталог.

Не заменяйте существующий одноимённый скилл молча: сравните версии и отдельно согласуйте обновление. Не меняйте глобальный `AGENTS.md`, `CLAUDE.md` или настройки модели ради установки.

## Установка через Python 3

Установщик использует только стандартную библиотеку. Если Python недоступен, используйте копирование папки; не требуется устанавливать Python или зависимости ради этого пакета.

Выполняйте из распакованной папки. `--destination` — **полный путь новой папки скилла**, не её родитель. Имя конечной папки должно быть `rf-site-legal-20`.

PowerShell, пример Codex при незаданном CODEX_HOME:

```powershell
python ./install.py --destination "$HOME/.codex/skills/rf-site-legal-20"
python ./install.py --destination "$HOME/.codex/skills/rf-site-legal-20" --install
```

Первая команда показывает план и ничего не меняет. Вторая копирует файлы после проверки контрольных сумм. Если используется нестандартный `CODEX_HOME`, замените путь на его фактический каталог `skills/rf-site-legal-20`.

macOS/Linux, пример Claude Code:

```sh
python3 ./install.py --destination "$HOME/.claude/skills/rf-site-legal-20"
python3 ./install.py --destination "$HOME/.claude/skills/rf-site-legal-20" --install
```

Для другого агента укажите его каталог вместо примера. Установщик намеренно не сканирует все приложения и не устанавливает ничего автоматически во все каталоги. Он не перезаписывает существующую папку, не удаляет файлы, не скачивает пакеты и не меняет конфигурацию агента. При ошибке копирования незавершённая новая папка может остаться на месте; автоматической очистки нет.

Контрольные суммы обнаруживают случайное изменение состава/содержимого, но не являются цифровой подписью и не доказывают доверенность источника архива.

## Подключение и проверка

Обновите список навыков или начните новый чат, если это требуется клиенту. Проверьте, что скилл появился в его списке. В Codex пример запроса:

```text
$rf-site-legal-20 проверь мой сайт по всем 20 пунктам, сверяй важные требования по актуальным источникам законодательства РФ и внедри применимые изменения в существующем стиле, без перекрытий страниц.
```

В Claude Code используйте `/rf-site-legal-20` или явно назовите навык в запросе. Автовыбор не отключён; фактическая активация зависит от клиента и настроек. Наличие папки само по себе не доказывает, что текущая сессия уже загрузила скилл.

Применение скилла не даёт агенту отдельного разрешения на публикацию, установку программ, подачу уведомлений, изменение аккаунтов или покупку лицензий. Пакет не является обещанием юридического соответствия сайта: агент должен проверить факты, действующие источники и реальные процессы каждого нового проекта.
