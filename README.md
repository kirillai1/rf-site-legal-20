# rf-site-legal-20

**20 проверок сайта или платформы по праву РФ — с актуальными источниками и аккуратным внедрением в дизайн.**

Переносимый [Agent Skill](https://agentskills.io/specification) для Codex, Claude Code, Cursor и других совместимых агентов. Помогает проверить персональные данные, согласия, cookie, условия, возвраты, реквизиты, доступность и права на материалы, затем внедрить применимые изменения в существующий продукт.

Это не набор готовых юридических обещаний и не автоматическая гарантия соответствия закону. Для каждого проекта агент проверяет фактические процессы и действующие нормы. Все 20 пунктов получают статус, включая обоснованное «не применимо».

## Два основных правила

1. **Сверять важную информацию по актуальным первичным источникам законодательства РФ.** Проверять статью, редакцию, дату вступления и применимость. Память модели, старый отчёт и поисковый сниппет не заменяют действующий документ.
2. **Добавлять информацию в стиле сайта или платформы пользователя.** Сохранять компоненты, типографику, цвета, отступы и адаптивность. Не перекрывать страницы, формы, CTA, меню и чат; не ломать рабочие сценарии и анимации.

## Быстрая установка

Через [Skills CLI](https://github.com/vercel-labs/skills) — нужен Node.js с npm/npx. Команды ниже скачивают CLI/скилл и выполняются пользователем при установке.

Показать доступный скилл без его установки:

```sh
npx skills add kirillai1/rf-site-legal-20 --list
```

Установить с выбором агента:

```sh
npx skills add kirillai1/rf-site-legal-20 --skill rf-site-legal-20
```

Установить глобально для Codex и Claude Code:

```sh
npx skills add kirillai1/rf-site-legal-20 --skill rf-site-legal-20 --agent codex claude-code --global
```

Установить глобально для всех поддерживаемых Skills CLI агентов:

```sh
npx skills add kirillai1/rf-site-legal-20 --skill rf-site-legal-20 --agent '*' --global
```

`'*'` оставляйте в кавычках. Команда нацелена на поддерживаемые CLI агенты, а не на любой существующий продукт. Для Windows или сред без поддержки symlink можно добавить `--copy`. Необязательный `--yes` пропускает подтверждения — используйте его только если это намеренное решение.

## Без Skills CLI

Клонируйте репозиторий или скачайте [ZIP исходников](https://github.com/kirillai1/rf-site-legal-20/archive/refs/heads/main.zip):

```sh
git clone https://github.com/kirillai1/rf-site-legal-20.git
cd rf-site-legal-20
```

Скопируйте внутреннюю папку `rf-site-legal-20/` целиком в каталог навыков выбранного агента. Или используйте установщик на Python 3 без дополнительных зависимостей.

PowerShell — Codex, стандартный пользовательский каталог:

```powershell
python ./install.py --destination "$HOME/.codex/skills/rf-site-legal-20"
python ./install.py --destination "$HOME/.codex/skills/rf-site-legal-20" --install
```

macOS/Linux — Claude Code:

```sh
python3 ./install.py --destination "$HOME/.claude/skills/rf-site-legal-20"
python3 ./install.py --destination "$HOME/.claude/skills/rf-site-legal-20" --install
```

Первая команда — план без записи. `--install` копирует скилл в явно выбранную **новую** папку после проверки контрольных сумм. Существующая папка не перезаписывается; глобальные настройки агента не меняются. При нестандартном `CODEX_HOME` укажите фактический путь. Подробнее: [INSTALL.md](INSTALL.md).

## Использование

Codex:

```text
$rf-site-legal-20 проверь мой сайт по всем 20 пунктам, сверь важные требования с актуальными источниками законодательства РФ и внедри применимые изменения в существующем стиле, без перекрытий страниц.
```

Claude Code:

```text
/rf-site-legal-20 проверь сайт и подготовь применимые изменения по праву РФ, сохранив его дизайн и пользовательские сценарии.
```

Для других клиентов явно назовите навык или выберите его через интерфейс. После установки обновите список навыков/начните новую сессию, если этого требует клиент. Автоматический выбор не отключён; активация зависит от клиента и его настроек.

## Какие 20 пунктов проверяются

| № | Направление | № | Направление |
|---|---|---|---|
| 1 | Политика обработки данных | 11 | Подтверждение заявлений и результатов |
| 2 | Условия использования | 12 | Альтернативные тексты изображений |
| 3 | Оплата, отказ и возврат | 13 | Контраст и читаемость |
| 4 | Cookie и другие хранилища | 14 | Клавиатура и доступность действий |
| 5 | Уведомление и выбор пользователя | 15 | Реальные реквизиты и контакты |
| 6 | Основания и согласия в формах | 16 | Возраст и законный представитель |
| 7 | Сторонние SDK и передачи данных | 17 | Несовершеннолетние и отписка |
| 8 | Тёмные паттерны | 18 | Лицензии шрифтов |
| 9 | Скрытые комиссии и платежи | 19 | Права на медиа, шаблоны и компоненты |
| 10 | Подлинность отзывов | 20 | Запросы по данным и их исполнение |

[Полная матрица](rf-site-legal-20/references/checklist-20.md) содержит критерии и ограничения каждого пункта. Отсутствующую функцию агент не должен создавать только ради списка.

## Какой результат должен дать агент

- Матрицу всех 20 пунктов: применимость, факты, источники, изменения, проверки и остатки.
- Правовые тексты, соответствующие подтверждённым фактам конкретного продукта.
- Изменения в существующих компонентах и страницах, проверенные в браузере и на узких экранах.
- Проверку реального поведения форм, согласий, подключений и способов обращения в доступном объёме.
- Чёткое разделение готового кода и вопросов, требующих действий владельца, хостинга или правообладателя.

## Границы

Нет обязательной привязки к Exa, MCP, framework или ОС. Нужны доступ к проекту и возможность проверить актуальные первичные источники; без них агент должен обозначить ограничения. Одна политика или checkbox не подтверждают исполнение юридических обязанностей.

Скилл не разрешает агенту самостоятельно публиковать сайт, устанавливать программы, подавать уведомления, менять аккаунты или покупать лицензии. Личные реквизиты и код исходного пользовательского сайта в репозитории отсутствуют.
